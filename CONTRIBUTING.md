# Contributing

1. Create an issue describing the proposed experiment or correction.
2. Create a short branch such as `feature/java-tree-map`.
3. Add or update tests with every code change.
4. Run `make validate` before opening a pull request.
5. Never edit raw result files manually. Regenerate them with the recorded command.
6. Report the machine, operating system, compiler/interpreter version and configuration.

Research results must be genuine. Fabricated, selectively removed or manually altered measurements will not be accepted.
